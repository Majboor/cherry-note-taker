Your notes, one click away in the menu bar.

Cherry keeps Markdown notes and everything you copy in a small window under your menu bar. Notes are plain files in a folder you own. No account, no cloud, free.

Install

Pick one. All three install the same signed app into Applications.

Homebrew

brew install --cask majboor/tap/cherry

Updates with brew upgrade.

Download

Open Cherry.dmg and drag Cherry into Applications. Then open it from Launchpad or Spotlight.

Look for the note icon in your menu bar.

Terminal

curl -fsSL https://cherry.waleeds.world/install.sh | bash

Downloads the DMG, checks its SHA-256 and Apple's notarization, installs and opens Cherry. Read the script.

Paste this into any coding agent that can run commands on your Mac. It reads the install guide, installs Cherry and tells you where your notes live.

What it does

A small native app: AppKit and WebKit, no dependencies.

Markdown notes

Write, edit and pin notes. Each one is a plain .md file you can open anywhere.

Clipboard history

Everything you copy, sorted into links, code, colours, errors, paths, images and files. Searchable.

Spotlight launchers

Every note gets its own launcher. ⌘Space, type the name, and you're there. Or ⌃⌥⌘C anywhere.

Images, PDFs and links

Paste or attach images and PDFs. [[Wiki links]] connect notes, with backlinks.

Screenshots tab

New screenshots and recordings show up on their own. Write a note on one in a click.

Made for agents too

Agents can write notes by saving files to the folder. Their run logs stay out of your list.
